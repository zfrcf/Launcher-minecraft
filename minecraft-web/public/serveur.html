Jouer dans le navigateur, avec ton compte Microsoft

Client Minecraft open source (réécrit de zéro, licence MIT), PC et mobile, connexion Microsoft intégrée. Un relais WebSocket fait le pont vers le serveur : celui du projet par défaut, ou le tien sur Render (dossier minecraft-navigateur).

Le jeu s'ouvre sur mcraft.fun. Le pseudo, l'inventaire et la progression sont ceux de ton compte. Rendu et FPS inférieurs au client officiel avec Sodium.

Se connecter (client officiel)

  1. PC (Java 1.21.11) : launcher officiel → connecté avec ton compte Microsoft → Multijoueur → Ajouter un serveur → adresse:25565.
  2. Mobile (application Minecraft) : Jouer → Serveurs → Ajouter un serveur → adresse adresse, port 19132. Le serveur doit avoir Geyser + Floodgate (fourni dans le dossier minecraft-serveur).
  3. Accès réservé : seuls les pseudos de la liste blanche entrent. Joueur mobile = pseudo préfixé d'un point (.Antoine).

Plus de FPS, moins de lag

  • PC : installer Sodium + Lithium (Fabric), distance de rendu 8-12, graphismes « Rapide », 4 Go de RAM alloués.
  • Mobile : distance de rendu 6-8, particules réduites, « Belles feuilles » désactivé.
  • Serveur : Paper + drapeaux Aikar (déjà configurés), distance de vue 8, simulation 6, serveur hébergé en France.
